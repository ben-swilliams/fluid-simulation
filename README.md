This repo contains all source code for my CS5199 dissertation project: "A Real-Time Smoothed Particle Hydrodynamics Framework for Interactive Fluid Simulation"

The submission zip itself contains standalone builds for Windows and MacOS, however for running the project for all of its capabilities, the intention is for it to run in the Unity Editor. The version used during development is 
was 6000.2.5f1, however any version afterwards should function at parity. The standalone Unity Editor archive can be found [here](https://unity.com/releases/editor/archive).

Included in both the editor and standalone builds is a built in UI allowing to change various aspects of the simulation, with a full description of each parameter being found in Appendix E of the dissertation 
PDF.
